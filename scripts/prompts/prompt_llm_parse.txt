Extraction Rules
1. Match rider names/codes (case-insensitive, flexible matching on variations)
2. For each rider identified, attempt to extract an associated numeric value immediately following or preceding the rider mention
3. If a value is found with the rider: output "CODE VALUE"
4. If NO value is found with the rider: output just "CODE"
5. Values: strip currency symbols ($), commas; "k" → ×1,000; must be positive integers
6. IGNORE any numbers that appear to be alone without clear rider context

Disambiguation
- "hospital" alone = DH (Daily Hospital Confinement), NOT HL unless explicitly "lump sum hospital"
- "cancer" default = LSCN unless "recurrence" or "100%" mentioned → LSCR
- "nursing" default = SN1 unless "option 2" or "21-100" or "day 21" mentioned → SN2
- "skin cancer" default = SC unless "recurrence" mentioned → SCR
- If the same rider appears multiple times, use the last value/mention

- Riders WITHOUT values: "CODE" (no number)
- Multiple riders: separate with single space (NO COMMAS)
- Use uppercase codes
